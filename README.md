# ESP-PMS5003

PMS5003 air particle concentration sensor driver for ESP-IDF (UART).

## Installation

To install this component in your project, run the following command:

```sh
idf.py add-dependency pkwasniok/pms5003
```

## Usage

See usage examples in the `examples/` directory.
